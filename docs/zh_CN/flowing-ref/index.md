# Flowing 精简参考教程

Flowing 是一个轻量式 Agent 框架，遵循“框架只提供机制，不提供策略”：核心提供运行时、消息流转、上下文组装和扩展点；重试、压缩、审批等策略由应用层组合。本精简参考分四篇介绍运行模型、消息树与上下文、能力描述与多智能体，以及装配控制与运行环境。

## 目录

1. [运行模型](01-运行模型.md)：配置模型、启动 Flowing 项目并完成一次对话。
2. [消息树与上下文](02-消息树与上下文.md)：理解消息模型、历史组织和上下文组装。
3. [三层能力描述与多智能体](03-三层能力描述与多智能体.md)：声明并绑定能力、实现工具并组织多智能体团队。
4. [装配控制与运行环境](04-装配控制与运行环境.md)：使用钩子、依赖注入、状态和取消机制，将 Flowing 接入实际应用。

每篇中需要的示例代码、配置、提示词、输入和记录输出都直接列在该篇正文中。第一篇从一个问答 Agent 开始，第三篇展示编排者与翻译专家协作，第二篇和第四篇用交互示例说明上下文观测、钩子与状态恢复。
