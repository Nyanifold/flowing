## 中文

### 框架核心

提供消息驱动的工作循环、消息级历史树、Context 装配、Tool / 子 Agent / Skill 能力描述、实例级钩子、provide-inject，以及持久化和崩溃恢复。

**用法：** 在 `main.py` 创建 Runtime 并挂载 `.fya` 根 Agent；通过 Agent 消息入口驱动回合。详情见[入门教程](https://flowing-agent.readthedocs.io/zh_CN/beginner-tutorial/)和[API 参考](https://flowing-agent.readthedocs.io/zh_CN/api.html)。

### 内置插件与 Composable

随包提供 Skills、Comm、Cron、Workflow、Clipboard 五个插件，以及 `use_retry`、`use_compact`、`use_auto_compact`、`use_system_reminder` 和 `use_prompt_until`。

**用法：** 在 Runtime 装配时通过 `runtime.install(plugin)` 显式安装所需插件；在 Agent 上调用对应的 `use_xxx(agent, ...)` 启用应用策略。

### `flowing` 命令行

提供 `repl`、`cli`、`repl-debug`、`run`、`test`、`serve`、`web` 和 `compile` 八个子命令。

**用法：** 在子项目目录运行 `uv run flowing repl .` 启动交互会话；运行 `uv run flowing --help` 查看全部命令。

### Provider adapter

提供 OpenAI 与 Anthropic API 格式家族及厂商 adapter；Provider 条目由 `providers.yaml` 配置并按需实例化。

**用法：** 在 `providers.yaml` 声明 Provider 条目并从模型配置引用；凭证可通过 `{{env.NAME}}` 引用环境变量。

### MCP Tool

MCP Tool 支持 stdio、SSE 和 streamable HTTP 连接方式，可接入外部 MCP Server。

**用法：** 声明 MCP Tool 的 Server 与连接类型，并将 Tool 绑定到 Agent。

### 双语文档

发布中文和英文的入门教程、详细教程、精简参考与 API 参考；发布时 700+ 测试用例通过。

**用法：** 选择[中文文档](https://flowing-agent.readthedocs.io/zh_CN/)或[英文文档](https://flowing-agent.readthedocs.io/en/)阅读。

## English

### Framework core

Provides a message-driven work loop, a message-level history tree, Context assembly, Tool / subagent / Skill capability descriptions, instance-level hooks, provide-inject, persistence, and crash recovery.

**Usage:** Create a Runtime in `main.py` and mount a `.fya` root Agent; use Agent message interfaces to drive turns. See the [beginner tutorial](https://flowing-agent.readthedocs.io/en/beginner-tutorial/) and [API reference](https://flowing-agent.readthedocs.io/en/api.html).

### Built-in plugins and Composables

The package includes five plugins—Skills, Comm, Cron, Workflow, and Clipboard—and `use_retry`, `use_compact`, `use_auto_compact`, `use_system_reminder`, and `use_prompt_until`.

**Usage:** Install the required plugins with `runtime.install(plugin)` while assembling the Runtime, then call the relevant `use_xxx(agent, ...)` to enable an application policy on an Agent.

### `flowing` CLI

Provides eight subcommands: `repl`, `cli`, `repl-debug`, `run`, `test`, `serve`, `web`, and `compile`.

**Usage:** Run `uv run flowing repl .` from a subproject directory to start an interactive session; run `uv run flowing --help` to see all commands.

### Provider adapters

Provides OpenAI and Anthropic API format families with vendor adapters. Provider entries are configured in `providers.yaml` and instantiated on demand.

**Usage:** Declare Provider entries in `providers.yaml` and reference them from model configuration. Credentials can use `{{env.NAME}}` to reference environment variables.

### MCP Tools

MCP Tools support stdio, SSE, and streamable HTTP connections to external MCP Servers.

**Usage:** Declare the MCP Server and connection type for an MCP Tool, then bind the Tool to an Agent.

### Bilingual documentation

Ships beginner tutorials, detailed tutorials, concise references, and API references in Chinese and English; more than 700 test cases passed at release.

**Usage:** Read the [Chinese documentation](https://flowing-agent.readthedocs.io/zh_CN/) or the [English documentation](https://flowing-agent.readthedocs.io/en/).
